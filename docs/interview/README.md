# Agent 实习面试证据入口

项目定位：**面向长程任务的 Coding Agent Harness**，能力主线为长期记忆、可观测执行、受控策略自优化。长程任务是目标场景，自优化是受限策略能力；不以“自进化”概括尚未验证的权重训练、任意代码自改和跨任务持续提升。

面试讲解按“任务约束 → 模块接缝 → 失败复现 → 设计取舍 → 原始证据 → 局限”展开。

本批是渐进重设计：新实现Runtime生命周期和统一观测，保留已交付的Session/Context/Artifact/Memory/Tools/Permission契约，并统一评测。模块文档明确区分原有能力和本批贡献，避免把既有能力再次记为新功能。

## 面试叙述边界

测试通过数量表示软件回归范围；离线夹具表示工程契约；真实任务评分表示指定模型、指定版本、指定小样本的结果。三者不能互换。工作由用户确定目标、主代理设计并验收、两名Sol助手执行；候选人应按自己能复现和解释的内容描述个人动作，不把协作过程写成未经核实的独立手写经历。

本轮新增[长程评测工程问题深挖](10-长程评测工程问题深挖.md)：P30–P35含九段证据链、预算状态机、消融混杂、环境预检、输入来源、跨语检索和效果边界。当前未测指标保持未测，后续结果持续追加。
