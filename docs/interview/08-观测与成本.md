# 观测与成本：辅助调用也进入证据链

## 面试要解释的问题

为何不用observer做硬预算？如何关联主请求与摘要？同步回调出错会否影响最终答案？

## 实现与取舍

新增不可变 CallStart / CallEnd、root/parent/purpose、无正文默认、provider用量快照；observer 快速同步回调且异常隔离，网络导出进入有界队列。提供本地 JSONL 与可选 Langfuse v5适配，不增加默认服务依赖。

Agent事件可记录工具但不足以完整记模型费用；统一门面覆盖摘要和记忆。丢弃时计 dropped，导出失败计 export_errors，关闭单独表达线程退出与 sink清理失败。

源码：`src/my_agent_llm/observation.py、observation_export.py、langfuse_export.py`。

## 本轮实际离线证据

运行：[`20261112T095857-2381042b458f`](../experiments/results/redesign/20261112T095857-2381042b458f/report.md)，seed=23，每个 arm 五次；完整运行共 12 个独立场景、100 条记录。

- `auxiliary_coverage` / `off` / `ablation`：观测 `{"actual_calls": 2, "coverage": 0.0, "linked_auxiliary": 0, "matched_ends": 0, "observed_calls": 0, "privacy_violations": 0}`；5/5 次满足各自预注册的夹具断言。

- `auxiliary_coverage` / `on` / `ablation`：观测 `{"actual_calls": 2, "coverage": 1.0, "linked_auxiliary": 1, "matched_ends": 2, "observed_calls": 2, "privacy_violations": 0}`；5/5 次满足各自预注册的夹具断言。

off组满足断言可能意味着它如预期暴露缺陷，不代表off更安全。contract没有开关；comparison的对照是有限wrapper，不能称生产模块可关闭消融。

## 遇到的问题与解决

独立复核发现 flush异常跳过own_client.shutdown，已改try/finally并添加失败回归；阻塞transport时close(timeout)返回False，不宣称线程已经回收。

## 优势、代价与不能据此宣称的结论

Langfuse早期用假client验证，后续已补真实5.2 SDK内存导出契约，真实服务上传仍未接通；本地指纹和span不能读取服务器KV状态。预算guard在调用前显式预留，不能靠observer抛异常拦请求。

## 复现

`python -m experiments.harness_eval --suite observation --repeats 5 --output <新目录> --seed 23`。需要从仓库工作目录加载 `src`；结果目录不可同名覆盖。使用脚本provider / 临时文件，模型tokens、cache、质量字段为null。

## 后续真实账本与统计更正

[v2真实小样本](../experiments/results/swe-v2-pilot-20261112/REPORT.md)的160请求用量全部结算，预算前预留、后结算累计$0.503462；这条证据来自本地guard/ledger，不代表Langfuse远端已接通或供应商实际扣款。cache_read字段只有158/160覆盖，cache_write为0/160覆盖，不能补零后给完整缓存排名。

官方empty_patch是已知未解决但未执行测试，原汇总曾误标环境错误。修复后将known_official_outcomes=10、test_executed=3、resolved=3和环境blocked=1分开；原state/report保留，纯parser可离线重派生。可解释的缺失与失败类别比只展示成功数字更有用。

## 后续Langfuse装配

全局Settings→RPC→CodingAgent装配Runtime，LLM五入口快照原observer和订阅；只detach/关闭自己拥有的资源，切换会话先完成旧Agent关闭。真实SDK验证标准input=total-completion，缓存与可能仅未缓存的prompt字段保留数字metadata，不重复计费、不补零。使用[全局配置示例](../integrations/README.md)，缺SDK/凭据不假装启用；内存transport契约不能替代云端上传后回读。
