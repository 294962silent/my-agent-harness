# 上下文与产物：有界视图和完整证据

## 面试要解释的问题

预览是否改变 canonical 历史？同 call_id 的不同内容会否覆盖？摘要相同尾部为何还要覆盖前缀指纹？

## 实现与取舍

保留 canonical 历史，按需生成发送视图；大工具输出落完整产物，模型先见头尾预览再受限回读。摘要覆盖来源校验和运行态快照沿用已交付实现，本批增加 Runtime deadline / 观测用途接线及统一证据。

直接截断最省实现成本却会丢证据；原文每次发送保留信息但增大输入。产物投影降低该夹具发送体积，付出额外落盘和回读成本。

源码：`src/my_agent_core/context.py、artifacts.py、src/my_coding_agent/tools/artifact.py`。

## 本轮实际离线证据

运行：[`20261112T095857-2381042b458f`](../experiments/results/redesign/20261112T095857-2381042b458f/report.md)，seed=23，每个 arm 五次；完整运行共 12 个独立场景、100 条记录。

- `artifact_roundtrip` / `off` / `ablation`：观测 `{"artifact_disk_bytes": 0, "artifact_readback_supported": 0, "evidence_recoverable": 1, "handles": 0, "source_bytes": 120019, "view_bytes": 120019, "view_contains_full_source": 1}`；5/5 次满足各自预注册的夹具断言。

- `artifact_roundtrip` / `on` / `ablation`：观测 `{"artifact_disk_bytes": 120361, "artifact_readback_matches_source": 1, "artifact_readback_supported": 1, "evidence_recoverable": 1, "handles": 1, "source_bytes": 120019, "view_bytes": 7041, "view_contains_full_source": 0}`；5/5 次满足各自预注册的夹具断言。

- `summary_source_binding` / `contract` / `contract`：观测 `{"changed_source_summary_leaks": 0, "summarizer_calls": 1, "unchanged_source_summary_reused": 1}`；5/5 次满足各自预注册的夹具断言。

off组满足断言可能意味着它如预期暴露缺陷，不代表off更安全。contract没有开关；comparison的对照是有限wrapper，不能称生产模块可关闭消融。

## 遇到的问题与解决

初版实验把 off 的 artifact_readback=0误解为没有证据，实际上原文已在视图内。现改为分别测工具支持、视图全文、两组可恢复性和磁盘字节，两组 evidence_recoverable 都是1。

## 优势、代价与不能据此宣称的结论

字节减少不能换算成 token / 费用 / KV 命中提升。有界采样和假摘要不能证明语义摘要保真；后者需要真实任务标注。

## 复现

`python -m experiments.harness_eval --suite context --repeats 5 --output <新目录> --seed 23`。需要从仓库工作目录加载 `src`；结果目录不可同名覆盖。使用脚本provider / 临时文件，模型tokens、cache、质量字段为null。
