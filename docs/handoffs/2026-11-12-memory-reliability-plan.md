# 长期记忆可靠性：取舍与执行计划

日期：2026-11-12。范围：当前本地 Markdown 记忆后端；用户授权主代理评价、决定改动并提交 GitHub。

## 取舍

本批选择六项小接口改进，而不是仅补正则，也不引入完整 provider / 跨会话 worker 架构。

1. **脱敏优先**：抽取请求发出前、记忆写盘前与工具回执 / 读取出口复用同一纯函数。覆盖常见凭据格式与敏感字段赋值，普通端口、路径、中文偏好正常保留。正则不能证明覆盖所有秘密；不批量改写旧历史文件，不声称提供通用 DLP。
2. **检索门控**：完整匹配琐碎问候、确认、继续及常见标点；含实际需求的输入仍检索，图片输入不能因空文字而误判为琐碎。
3. **全文回读**：独立只读 `memory_read` 工具，以 subject + key 精确定位，不接受任意文件路径。检索预览提示裁剪与全文入口；修改事实前先核对全文。
4. **显式删除**：扩展现有 `memory` 工具，删除指定事实及其历史，立即更新索引；重新加载不得从旧 JSONL 复活。写盘错误必须暴露，不能回报假成功。路径规范化碰撞不能删错、覆盖另一条事实。
5. **压缩前抽取**：在自动 / 手动压缩的共同接缝提供可选回调，读取 canonical 待覆盖原消息。启用自动蒸馏时接入；抽取有超时，失败允许继续压缩，取消向上传播。这是 best-effort，区别于 Hermes 的可选 fail-closed 检查点。只提取有用户依据的持久事实，排除运行态与检索注入。
6. **空闲蒸馏**：启用自动蒸馏后，响应结束只安排任务；空闲后才抽取。任务有句柄、超时、取消及异常回收；新输入 / 重置 / 中止 / 关闭使旧任务失效，落盘前复验 Session 与分支。默认仍不启用自动蒸馏。当前进程内任务不等同可恢复的跨会话后台服务。

空闲延时拟为可配置 30 秒、抽取超时 15 秒，以最终代码和验证为准。这些是本项目的选择，不是 oh-my-pi 的默认值。退出进程可能取消尚未运行的空闲任务；显式记忆写入与压缩前抽取不依赖其最终完成。

## 职责与依赖

- SOL-2：MemoryStore、索引、脱敏函数、全文工具与删除，以及存储回归。
- SOL-1：Agent / Context 接缝、生命周期、检索门控和工具注册，以及假 LLM 回归。
- 主代理：方案、实验记录、集成验证、明确路径暂存、GitHub 交付。
- 独立复核：审查行为、取消 / 失败路径、删除后恢复与提交树依赖。

两个执行助手使用 GPT-6.1 Sol / medium；不使用 DS / DSH，不运行真实 API、性能实验或 GPU 作业。

## 验收与提交

- 有针对性的失败测试先复现缺口，再运行记忆、压缩、Agent 与 CodingAgent 相关离线回归；运行 Ruff、差异空白检查。
- 用假 LLM 检查响应返回不等待蒸馏、空闲触发、重入取消、分支失效、超时、抽取前脱敏及失败不假成功。
- 用真实临时目录检查重载、全文、删除、legacy 迁移、中文键碰撞与 I/O 失败。
- 保留已有未提交调度工作与用户文档改动。先投影并验证独立的上轮上下文提交，再加入本轮记忆提交；不整库暂存。
- 对将要推送的完整提交树另行验收。只推用户 `origin`，不推 `upstream`，不自动合并。CI 状态以实际返回为准。
- 每批更新 `docs/experiments/HARNESS_EXPERIMENT_LOG.md`，写清前后行为、证据、代价与未完成项。

- 用户提供的固定版本：oh-my-pi `fec500b7a891`（写入脱敏、空闲处理、全文回读）；Hermes `5df966a97a2d`（pre-compress 接缝、琐碎输入门控）。依据见学习文档 04A 第 11 节，保留其“树过滤及关键文件核验，未逐行全库审计”的边界。
